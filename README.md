# 🛒 MyStore Dataset Analysis with Power BI

This project showcases interactive data visualizations and business insights generated from the MyStore dataset using Microsoft Power BI. The dashboard is designed to help understand sales performance, product trends, customer behavior, and regional performance.

## 📁 Project Structure


## 📌 Objectives

- Analyze sales performance by category, region, and segment
- Identify top-performing products and sales reps
- Track profit margins and discount impact
- Provide a visual summary for quick decision-making

## 🧰 Tools Used

- **Power BI Desktop**
- **Microsoft Excel / CSV** (for initial data)
- **DAX** (Data Analysis Expressions)
- **Power Query** (for data transformation)

## 🔍 Key Insights

- 📈 **Sales & Profit Trends**: Month-over-month comparison
- 🗺️ **Geo Analysis**: Sales by region and country
- 🛍️ **Product Insights**: Top and bottom-performing products
- 💰 **Discount Impact**: How discounts affect profits
- 👥 **Customer Segments**: Sales by customer type and segment

## 📊 Dashboards Include

- **Overview Page** – KPIs for sales, profit, and quantity
- **Category Analysis** – Sales by category and sub-category
- **Region Map** – Geo-visual of regional performance
- **Time Series** – Monthly trends and YoY comparisons
- **Customer Segment Analysis** – Sales by customer type

## 🚀 How to Use

1. Clone or download the repository
2. Open `MyStore_Dashboard.pbix` using Power BI Desktop
3. Explore the dashboards and visuals
4. Modify data or visuals as needed

## 📄 Dataset Info

- Fields include: `Order ID`, `Order Date`, `Ship Mode`, `Customer Segment`, `Region`, `Product Category`, `Sales`, `Quantity`, `Discount`, `Profit`
- Simulated dataset (similar to Superstore) for BI learning and reporting
